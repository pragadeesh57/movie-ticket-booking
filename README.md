# 🎬 Movie Ticket Booking System

A web-based Movie Ticket Booking System developed using **Java, Spring Boot, Spring Data JPA, and MySQL**, with an automated **CI/CD pipeline using Jenkins, Docker, and AWS**.

## 🚀 Features

- View available movies
- Add movies
- Book movie tickets
- MySQL database integration
- Automated CI/CD pipeline
- Docker containerization
- AWS deployment

## 🛠️ Technologies Used

**Application:** Java, Spring Boot, Spring Data JPA, HTML, CSS, MySQL, Maven

**DevOps & Cloud:** Git, GitHub, Jenkins, Docker, AWS EC2, Linux
